# online store
此專案旨在設計一網站模擬電子商務網站的服務與功能，主要就瀏覽商品、登入至購物車結帳進行設計，提供完整且流暢的消費流程體驗。

## 關於專案
此網站是基於增進自己網頁前端設計能力而開發，具響應式設計(RWD)。專案採 Next 全端框架與無伺服器資料庫 Firebase 開發，前後端以 Restful API 串接，再由後端與資料庫溝通，CI/CD 則使用 Vercel 進行自動部屬。
